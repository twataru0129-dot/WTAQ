# ナレーション修正前後の比較サンプル（v1 → v2）

各 `*_compare.wav` は「修正前 → 1秒の無音 → 修正後」の順で続けて再生されます。修正前と修正後を別々に聞きたい場合は `*_v1_before.wav` / `*_v2_after.wav` を使ってください。どれも -23 LUFS にそろえてあります。
`pitch_compare.png` は声の高さ（F0）の比較グラフです。

アクセントは `'` の直後で音が下がる位置、`/` は句の区切り、`、` は短い間、`_` は無声化を表します。句末に `'` があるものは平板です。

## 1. 冒頭の問いかけ（scene01）

| | 読みとアクセント |
|---|---|
| v1 | デ'モ、ソノ'/アタリマエオ'/ササエ'テ/**イル'/ノワ'**、ダ'レデショオ？（エンジンの上昇調を付加） |
| v2 | デ'モ、ソノ'/アタリマエオ'/**ササエテイルノワ'**、ダ'レデショウ（最後のモーラだけ緩やかに上げる） |

- 「支えているのは」が3つの句に割れて、イル・ノワが独立して持ち上がっていたのを1句にまとめた
- 文末は、エンジンが付ける上昇（約 +45%）をやめて、最後の「う」だけを約 +20% 上げる穏やかな問いかけにした

## 2. 会社名の説明（scene02）

| | 読みとアクセント |
|---|---|
| v1 | ワタキュウセ'イモアワ ｜ シ'イツナドオ/**カイシュウ'/シ'** ｜ アライ'、ケ'ンサ/**_シテ'**/トドケ'ル/カイシャデ'_ス（3回に分けて合成し、つないでいた） |
| v2 | ワタキュウセ'イモアワ、シ'イツナドオ/**カイシュウシ'**、アライ'、**ケ'ンサ_シテ**/トドケ'ル/カイシャデ'_ス（1文を1回で合成） |

- 「ワタキューセイモア」は「セ」の後で下がる読みをユーザー辞書に登録した（再生成時も自動で反映される）
- 「回収し」「検査して」が動詞部分で切れていたのを1句にまとめた
- 3つの断片をつなぐのをやめ、1文を1回で合成することで、つなぎ目の不自然さと句ごとの抑揚のリセットをなくした
- 単語ごとの高い山（v1 では 220Hz 超）を圧縮した（最大 約190Hz）

## 3. 数字を読む場面（scene05）

| | 読みとアクセント |
|---|---|
| v1 | ヤ'ク/**イチ'ネン/ヨンカ'ゲツデ** … ヤ'ク/**ナ'ナジュウ/ニ'イテン/ロク'トン** ｜ センタクワ' ｜ **サンゼ'ンヒャク/ナナジュッ'カイ、イ'ジョオ** |
| v2 | ヤ'ク/**イチネンヨンカ'ゲツデ**、ショ'リ_シタ/リ'ネンワ、ヤ'ク/**ナナジュウニテンロ'クトン** ／ センタクワ'、**サンゼンヒャクナナジュ'ッカイ/イ'ジョオ** |

- 「1年4か月」「72.6トン」「3,170回」を、それぞれ1つのまとまり（1アクセント句）として読む
- 「3,170回」と「以上」の間の不要な間をなくした
- 長い数字で高い平坦が続かないよう、句の中で少しずつ下げる

## 全編共通の設定（`src/data/script.json` の `voiceV2`）

- 話者：玄野武宏（ノーマル）のまま。話速 0.93、声の高さ 0（v1 と同じ）
- 抑揚の強さ 0.95（v1：1.05）
- 山の圧縮：文の中央値から 0.3（自然対数、約 +35%）を超える部分を半分に
- 下降：文の後ろの句ほど 0.015 ずつ（最大 0.08）、句の中でモーラごとに 0.008 下げる
- 文末：最後の2モーラを 0.03／0.07 下げ、最後のモーラを 1.12 倍に伸ばす（説明文のみ）
- 疑問文：最後の有声モーラを 0.34 上げ、1.6 倍に伸ばす（scene01 の問いかけのみ）
- 平板な句の末尾の助詞が、直前の音より高くならないようにそろえる
